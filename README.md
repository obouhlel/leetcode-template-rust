# Leetcode template in rust

![Rust](https://img.shields.io/badge/Rust-2021-orange)

A simple repository to create a Leetcode template in Rust.

## Dependencies

To use this template, you need to have [`cargo-generate`](https://crates.io/crates/cargo-generate) installed. You can install it using the following command:

```bash
cargo install cargo-generate
```

## Usage

To generate a new project using this template, run the following command:

```bash
cargo generate --git https://github.com/obouhlel/leetcode-template-rust
```
